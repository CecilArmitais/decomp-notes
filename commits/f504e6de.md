## What the argument types rest on

**Fact.** Three helpers were already declared in `move_orb_effects.h`, and those
declarations fix what the constants mean:

- `LowerSpeed(user, target, s32 nStages, bool8 displayMessage)` → String Shot
  lowers speed by one stage and shows the message.
- `TryInflictParalysisStatus(user, target, bool8 displayMessage, bool8 onlyCheck)`
  → the paralysis wrapper displays the message and is not a check-only call.
- `BoostSpeedOneStage(user, target, s32 turns, bool8 displayMessage)` → Boost
  Speed 1 passes `turns = 0`.

**Inference, and weak.** The other seven helpers are undeclared anywhere in the
tree, so their prototypes here were written from the call site with the loosest
types that compile, and the parameter *names* in those externs
(`onlyCheck`, `displayMessage`, `fromMove`, `status`) are **guesses carried over
from the analogous declared helpers**. Nothing in this commit verifies them. A
reviewer should treat those names as placeholders; the constants are facts, the
names attached to them are not.

`SetReflectStatus(attacker, defender, 4)` for Counter is the weakest of the set —
`4` is presumably a status-variant selector, and this commit establishes only
that the value is 4.

## Process

**Fact.** The scratch context was generated from the real headers before writing
any candidate, rather than hand-assembled. That is the direct consequence of
[`e8823a88`](e8823a88.md), where a hand-built context scored 0 on a function the
real build compiled differently. Ten first-try matches is consistent with the
context being faithful, though ten small wrappers are a weak test of it.

**Fact.** None of the ten carries a region conditional, checked by listing
preprocessor directives inside each `arm_func_start`/`arm_func_end` block
before building. US alone is therefore sufficient; EU and JP were not built.
