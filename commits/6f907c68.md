**Fact.** Most are tail calls the compiler reaches with `bx` rather than `bl`,
either passing arguments through unchanged or supplying one:
`PlaySeByIdVolumeWrapper` fixes the volume at `0x100`, the two Oam wrappers
offset their argument by `0x20`, and `CopyAndInterleaveWrapper` halves its
length.

## Shift, not divide

**Fact.** That halving is a **shift**, not a division. Written as `len / 2` the
compiler adds the round-toward-zero correction a signed divide needs; the target
has a bare `asr #1`, which is what `len >> 1` produces.

## The caution that matters most here

**A veneer that only forwards constrains nothing about its own argument list.**

**Fact.** The arguments are already in the right registers, so declaring **none,
one or several all produce the same bytes.** The parameter lists are therefore
**chosen to read sensibly against each callee's name, not read off the target.**

**The one exception, and it is real evidence:** `PlaySeByIdVolumeWrapper`'s
signature is pinned by an existing C caller in `overlay_25_init.c` that passes a
single `s32`.

A reviewer should treat seven of these eight signatures as **conventions, not
findings**. This is the same underdetermination as
[`d4b2c2fc`](d4b2c2fc.md) and [`e6c5c875`](e6c5c875.md).
