## Nested `if`, not early return

**Fact, measured.** Both mission predicates are `A || B` in effect, and both only
match written as a nested `if` falling through to one `return`:

```c
/* 610 / 405 */                      /* 0 */
if (A) return TRUE;                  if (!A && !B) {
if (!B) return FALSE;                    return FALSE;
return TRUE;                         }
                                     return TRUE;
```

This is the same knob `MATCHING_TIPS.md` records under *converge on one `return`
to get a branch, not predication* — reached here from the opposite direction,
since the obvious spelling was the early-return one.

## Declarations that already existed

**Fact.** Both predicates merged into files that **already declared**
`IsCurrentMissionType(enum mission_type)` and
`IsCurrentMissionTypeExact(enum mission_type, u8)` further down. The landing
script inserted fresh `extern … (s32 type)` versions at the top of each file,
which the compiler rejected as redeclarations — the one useful thing about the
error is that it surfaced immediately rather than silently.

Removed in favour of the existing declarations, and the constants written as
`MISSION_ARREST_OUTLAW`, `MISSION_TAKE_ITEM_FROM_OUTLAW` and
`MISSION_CHALLENGE_REQUEST` (10, 9, 11) rather than raw numbers.

**Inference.** `IsLegendaryChallengeFloor`'s floor test is
`(u8)(mission_destination.subtype + 0xFF) <= 4` — a byte decrement written as
`+ 0xFF`, the same encoding `DoMoveGust` needed in
[`80d0e710`](80d0e710.md). Twice now in this branch, so it is worth treating as
the default reading when a byte compare is preceded by `add #0xFF`.
