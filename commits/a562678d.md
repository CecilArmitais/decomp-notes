`ActivateEndOfTurnEffects` (`0x0230FC24`, **1235 instructions** in US) is the
per-turn status tick: the warp-scarf counter, the leader's belly and hunger
messages, weather damage, Shed Skin and Hydration, the burn / poison /
bad-poison / constriction / wrap / ingrain / curse / leech-seed damage
countdowns, perish song and bide. Its body is a flat chain of 23 guarded blocks
with a single exit.

## Landing shape

**Fact.** It is the last of five functions in `asm/overlay_29_0230F9A4.s`, and
`main.lsf:1002-1004` puts `asm/overlay_29_0230F9A4.o` between two `src/`
objects, so `extract_function.py` merges into `src/overlay_29_02311010.c` above
`EntityIsValid__02311010` and **`main.lsf` is unchanged**. That header already
declared the three `__02311010`-family helpers the body calls.

## The shared-header change

**Fact.** `struct monster` declared `0xAC` as `u8 bide_move_id; u8 field_0xad;`.
Retail accesses it with `ldrh`/`strh` and stores `0x165` — which does not fit in
a byte. The field becomes `enum move_id` and absorbs `field_0xad`.

| claim | kind | evidence |
|---|---|---|
| the stored value is a move id | fact | `0x165 = 357 = MOVE_BIDE_UNLEASH` (`include/enums.h`), which is what the field's existing name says it holds |
| `enum move_id` is two bytes here | fact | it runs to `MOVE_TAG_0x22E = 558`, so `-enum min` cannot shrink it below 16 bits |
| …and the tree already relies on that width | fact | `struct move` (`include/common.h:20-31`) has `enum move_id id; // 0x2` between `u8 field_0x1` at 0x1 and `u8 ginseng` at 0x4 |
| the change is layout-neutral | fact | eight compile-time assertions passed — `bide_move_id` at 0xAC, **`unique_id` still at 0xB0**, `bide_damage_tally` at 0xB8, `belly` at 0x146, `famished` at 0x150, `field_0x17c` at 0x17C, `sizeof(struct monster) == 0x240`, `sizeof(enum move_id) == 2` — and a full matching build with the change alone |
| nothing else reads the members | fact | grep of `src/` and `include/` for `bide_move_id` and `field_0xad` |

This deviates from pmdsky-debug's `u8` and is worth raising there — the same
kind of correction as [`24d1e500`](24d1e500.md)'s and
[`5271b77a`](5271b77a.md)'s. `InitMove` already takes `enum move_id`, so the
typed field feeds it with no cast and no `-W error` enum-conversion problem,
which a plain `u16` would have caused.

## The match

Scratch `current_score: 0` for **all three regions**, each measured against a
context and source obtained by preprocessing the *landed* `.c` for that region —
so the `#if`s and `#define`s above are resolved by the real preprocessor rather
than modelled.

**How it was reached**, in outline (the workspace's
`wip/ActivateEndOfTurnEffects/README.md` has the rounds): the body was drafted
in seven slices and independently re-read against the asm; seven region owners
closed the structural rows; then the entire residue was a single callee-saved
**rotation** — 538 rows differing only in which register held which value, with
the instruction stream already exact at 1275 rows on both sides.

That rotation was closed by hoisting every local to function scope and ordering
the declaration list the way the target's registers spell it out. The mechanism,
as far as it was established: **the allocator's unit is the coalesced web, not
the source variable** — splitting the parameter into three successive aliases is
byte-identical, because MWCC coalesces them back — and the function-scope
declaration list is the only thing that orders those webs. A *partial* hoist
leaves the axis absent entirely.

Four independent attempts from four different starting strategies converged on
the same answer, which is the main reason to believe it is the right shape
rather than a lucky spelling.

## Open questions for a reviewer

- `bide_move_id` as `enum move_id` contradicts pmdsky-debug's `u8`; codegen
  requires 16 bits.
- The `void` return is inference.
- The 29 provisional callee prototypes are guesses from call sites and should be
  replaced by includes as those callees land. One debt is pre-existing and still
  open: `ov29_022EA370` is declared `s32 ov29_022EA370();` at
  `src/overlay_29_022F0EDC.c:85` and `void ov29_022EA370(s32, s32)` at two other
  sites; this file calls it with two arguments.
- Whether the twelve-local form (temps reused across blocks) or the twenty-one
  local form (every temp distinct) is closer to the original cannot be settled
  from the bytes — both reach 0. The shorter one was taken.
