## A stale declaration retired, as the process requires

**Fact.** `src/overlay_29_022F0EDC.c` (`SetLeaderAction`) carried
`extern struct monster *GetLeaderMonster();` — a provisional prototype written
from the call site when that function was landed, with an empty parameter list.
`GetLeaderMonster` is decompiled here and merged into `dg_uty.h` beside
`GetLeader`, so the extern is deleted; that file already includes `dg_uty.h`,
which now declares it as `(void)`.

This is the case `CLAUDE.md` describes: a build cannot catch two declarations in
two translation units, so retiring the provisional one is a manual step that has
to be remembered when the callee finally lands. It was, here, because the
landing tripped over it.

## What rests on existing types

**Fact.** `SetDungeonRngPreseed`, `GetDungeonRngPreseed` and
`SetDungeonRngPreseed23Bit` read and write offset 8 of `DUNGEON_PRNG_STATE`,
which is `prng_state::preseed` in `dg_random.h`. Combined with
[`e029b3cb`](e029b3cb.md), which used offsets 0 and 0x10 of the same struct,
five independent functions now agree with that layout.

**Fact.** `SetDungeonRngPreseed23Bit` sets bit 0 and clears the top byte
(`orr #1` then `bic #0xff000000`), leaving 23 significant bits — which is what
its pmdsky-debug name says, so name and bytes agree.

## What is provisional

**Inference, weak.** `FindNearbyUnoccupiedTile` and the three displacement
tables (`DISPLACEMENTS_WITHIN_2_SMALLEST_FIRST`,
`..._2_LARGEST_FIRST`, `..._WITHIN_3`) are undeclared anywhere in the tree.
Their prototypes here are written from these three call sites: the wrappers pass
a table, a count (`0x19` for the within-2 tables, `0x31` for within-3) and
forward their own third argument. **The element type of the tables is a guess**
— they are declared `const s32 []` because that compiles and matches, not
because anything establishes it. A displacement table would more plausibly hold
pairs or `struct position`; a reviewer should treat the type as unknown.

**Fact.** `ov29_02353560` gets a placeholder `struct unk_02353560`; only its
byte at offset 3 is used by the two functions landed here.
