## A difference that is not an omission

**Fact, and flagged deliberately.** `CloseAdvancedMenu` differs from the simple-
and parent-menu versions: **it frees only the window contents, not the pointer at
`0x198` those two free first.**

**That is what the target does and is not an omission here.** Same category as
`CountNbItemsOfTypeInBag`'s missing existence check in
[`a49bcedf`](a49bcedf.md) -- an asymmetry a reviewer would reasonably flag, which
the asm justifies.

**Fact.** `IsAdvancedMenuActive2` tests the same states as `IsSimpleMenuActive`,
7 and 8, and like it binds the state to a local so the field is loaded once.

**Fact.** `SetAdvancedTextBoxField0x1C2` stores a **constant 1** rather than an
argument, so it takes only the window id. Its name notwithstanding, it is not a
general setter.
