## The finding: an `s16` index folds into `smlabb`

**Fact, with a measured cost.** `GetItemAtIdx`'s index parameter is **`s16`, not
`s32`**. `struct item` is 6 bytes, and at 16-bit width the compiler folds the
index scaling and the base into a single `smlabb`, which is what the target
emits. **An `s32` index produces a separate multiply and add, at score 1100.**

This is one of the highest-value single-token findings on the branch, and it
recurs -- the same `(s16)` subscript trick appears in
[`86d3db8f`](86d3db8f.md).

**Fact.** `GetItemAtIdx` returns a pointer into the active inventory, or null for
a negative index.
