## The context investment paying off

**Nine of ten matched on the first candidate** — and, more to the point, they
matched *in the build* rather than appearing to on a scratch and then failing.

These are the first functions verified against the preprocessed `dungeon.h`
context built in [`5c895f8a`](5c895f8a.md) instead of a hand-written struct. The
setup cost is now paid once, and a scan finds **59 more small `DUNGEON_PTR`
functions** across overlay_29 that can reuse it.

That is worth stating as the practical lesson from the whole overlay_29 episode:
the faithful context looked like an expensive detour, and it converted a cluster
that was costing ~6 minutes per question into one where ten functions land in a
single build.

## `GetMinimapData` wanted the expression form

**Fact.** The null check has to be a conditional expression, not an `if` with an
early return. The target predicates the whole body — `addne` twice for the
non-null path, then `moveq` for the null one — where the statement form branches.

```c
struct dungeon *dungeon = DUNGEON_PTR;

return dungeon != NULL ? &dungeon->minimap_display_data : NULL;
```

Same predicate-ordering effect as the LFO handlers in
[`909484fb`](909484fb.md), but pointing the other way: there the *statement* form
was needed to reverse `movne`/`moveq`, here the *expression* form is needed to
get predication at all. **The rule is not "prefer one form" — it is to read which
one the target emitted.**

## Version differences need nothing in the C

**Fact.** The US and JP offsets differ for the `gen_info` and minimap fields, and
the asm carries that as `#ifdef JAPAN`. **The C needs no conditional**: the
fields have the same names in both versions, so `dungeon.h` resolves each build
to its own offset.

Worth recording because the asm's `#ifdef` blocks look like they demand
version-specific C, and for field accesses they do not. (Contrast
`sub_02027AA0` and `sub_0202760C` in the window cluster, which genuinely do —
there the *same* struct field is at different offsets *within one version's*
layout, not a field renamed across versions.)
