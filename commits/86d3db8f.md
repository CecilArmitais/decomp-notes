## Decompiled

The three member-index predicates from `asm/main_02054E4C.s`, into a new
`src/main_02055410.c`.

**Fact.** Each takes a member index, checks `TEAM_MEMBER_TABLE_PTR->members[idx]`
is valid, and returns whether that index is the one a particular main character
occupies for the current game mode: `sub_02055410` tests index 2 in a special
episode and 0 otherwise; `sub_02055474` tests 3 and 1; `sub_020554D8` tests 4 and
is false outside a special episode.

**Inference, well supported.** Those are the same indices `GetMainCharacter1/2/3`
select, so each predicate answers *"is this index that main character"* without
going through the accessor.

## Two typing facts

**Fact.** The return type is `bool8` rather than `int`.

**Fact.** The parameter is subscripted as `members[(s16)idx]` so the index
multiply compiles to `smulbb`. The cast is not cosmetic -- it is what selects the
16x16 multiply the target uses.

## A header self-containment trap

**Fact, and it generalises.** The new header includes `util.h`. Without it the
header is **not self-contained**: `bool8` is declared there, and a header using
it before `common.h` is reached makes the compiler infer `int` and then conflict
with the real typedef.

This class of failure recurs across the branch and is recorded in
`docs/INSERTING_AND_BUILDING.md`. The confusing part is that the error text
prints both declarations, which look identical.
