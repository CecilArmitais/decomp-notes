## Three spellings that decided the match

**Fact, all measured.**

1. **`IsOutlawOrChallengeRequestFloor`** is three ORed predicates and matches
   only with each operand written `!= 0`. A plain `||` scores **300**; the
   early-return form **1300**. Note this is the *opposite* of
   [`901ba2aa`](901ba2aa.md), where two-term predicates wanted a nested `if`
   falling through — so "how a boolean chain is written" is not one rule but
   several, and the count of terms appears to matter.
2. **`DoMoveBubble`** returns whether *damage* was dealt, not whether the speed
   drop landed: the asm sets `r4 = 1` before the random check and returns `r4`
   regardless of its outcome. Funnelled through one variable, which is also
   passed as `LowerSpeed`'s stage count — the same register serving both.
3. **`sub_0205BCC4`** must not hoist the destination pointer above its `NULL`
   check. A local shared by both branches scores **830**; declaring it inside
   the `else` branch matches.

## A padding gap named

**Fact.** `sub_0202AAE8` and `sub_0202BC60` are the same function over different
window states, and both write a byte at `0x1A1` of `struct unk_0202AAA8`, which
the header covered only as implicit padding after `u8 field_0x1A0`. Now
`field_0x1A0` / `field_0x1A1` / `field_0x1A2[2]` / `field_0x1A4` — same total
size, same later offsets.

**Inference.** The two functions differ only in which state values they accept
(4/5/9 → 7, and 3/4/10/8 → 6). They are almost certainly the same routine
instantiated for two menu kinds, but nothing here establishes what the states
mean.

## Not landed

- **`DoMoveTickle`** (`asm/overlay_29_023276E8.s`) reaches `ATK_STAT_IDX` as
  `SPATK_STAT_IDX + 4` — the asm loads the pool entry for `SPATK_STAT_IDX` and
  offsets by 4, because the two globals are adjacent in `rodata`. Naming
  `ATK_STAT_IDX` directly emits offset 0 and misses by one instruction (score
  **15**). The original source evidently reached it through the neighbouring
  symbol, and no natural spelling for that has been found.
- **Incidental corroboration**: those globals live in
  `asm/overlay_29_rodata_02352A6C.s` — *rodata*, which independently supports
  the `const` typing introduced in [`1bcd9852`](1bcd9852.md) on scheduling
  evidence alone.
